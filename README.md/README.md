# Vendor Payment Process Optimization System

## Project Overview

This project focuses on designing an Excel-based Vendor Payment Management System to improve invoice processing, approval tracking, payment monitoring, and operational efficiency.

The project uses a simulated business scenario where the existing vendor payment turnaround time is 18 days, with a proposed target of reducing it to 6 days.

## Business Problem

The existing vendor payment process faces potential challenges such as:

- Manual invoice processing
- Delayed invoice verification
- Slow approval cycles
- Lack of centralized payment tracking
- Limited visibility into pending and overdue payments

These challenges can affect operational efficiency and vendor relationships.

## Project Objectives

1. Develop a centralized vendor invoice register.
2. Track invoice verification and approval stages.
3. Monitor payment due dates and actual payment dates.
4. Identify pending and overdue invoices.
5. Build an interactive management dashboard.
6. Analyse payment turnaround time.
7. Evaluate process improvements against a six-day target.
